# Specs

Specifications for Spec-Driven Development (SDD). Write the spec **before** implementing.

- Active specs: `specs/YYYY-MM-DD-slug.md`
- Fully implemented specs: move to `specs/implemented/`
- Superseded, abandoned or obsolete specs: move to `specs/archive/`

Naming: `YYYY-MM-DD-slug.md` — date the spec was created, lowercase kebab-case slug.

Suggested sections: Context, Goals, Non-goals, Requirements, Design, Acceptance criteria, Open questions, Status.
