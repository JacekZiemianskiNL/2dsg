# Claude Code notes

The `.ai/` workflow in AGENTS.md is mandatory for Claude Code sessions:

- Read `.ai/lessons.md` before starting work.
- Write or follow a spec in `.ai/specs/` (`YYYY-MM-DD-slug.md`) before non-trivial changes; move it to `implemented/` or `archive/` when done.
- Create a run log in `.ai/runs/YYYY-MM-DD-slug.md` for every autonomous/background run.
- Record lessons in `.ai/lessons/` and index them in `.ai/lessons.md` after fixing bugs or learning something worth remembering.
